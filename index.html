🎓 BZU · CASPAM · Session 2022–2026

University AI Analytics Agent

An Intelligent Conversational System for Academic Data Analysis

Supervisor: Dr. Shehzad Ahmad
Dept: CASPAM – BZU Multan
Session: 2022 – 2026

A production-grade AI-powered academic analytics system that combines Large Language Models (LLMs), RAG retrieval, and Machine Learning for intelligent conversational university data analysis. The system allows natural language querying over university datasets, providing instant insights, predictions, and visual analytics.

Problem Statement

  • No natural language query system in universities
  • Difficult identification of at-risk students
  • Manual Excel/SQL dependency
  • No cross-department analytics

System Architecture

  • Streamlit Web Interface
  • AI Agent Core
  • LLaMA 3.3-70B via Groq
  • RAG Engine (TF-IDF / FAISS)
  • ML Prediction Model
  • Data Layer (CSV / Excel / JSON)

Key Features

  • Schema-Agnostic Design
  • Long-Wide Auto Pivot
  • Context-Aware Memory
  • Graceful FAISS Fallback
  • Natural Language Querying
  • ML-Based Prediction
  • Multi-dataset Integration
  • LMS Integration
